# Batchim (받침)

A single-page Korean study site that fits a six-phase plan to any start and target date, from reading Hangul correctly to getting through your first weeks in Korea.

받침 is the consonant at the bottom of a Korean syllable. The word means "support underneath."

## What's inside

- **Plan**: six phases (Hangul, sentence skeleton, verbs and time, connecting ideas, survival scenarios, final prep) stretched or compressed to fit your dates, each with tasks and an exit test
- **Hangul**: vowels, consonants, syllable building, plain vs aspirated vs tense consonants
- **Sound rules**: carryover, nasalization, palatalization, ㅎ rules, final sounds, tensing, double ㄹ
- **Grammar**: 28 lessons with forms, examples and common mistakes
- **Words**: 247 core words with spaced-repetition flashcards
- **Verbs**: a conjugator for 83 verbs and adjectives, including irregulars
- **Numbers**: Sino-Korean and native systems, counters, time, dates, and a number reader
- **Phrases**: survival phrases for food, transport, paperwork, campus, housing, health and emergencies
- **Culture**: speech levels, titles, honorifics, etiquette, Gyeongsang dialect
- **Drills**: letters, sound rules, particles, verb forms, vocabulary

## Running it

It's one static file with no build step. Open `index.html` in a browser, or serve the folder with any static host.

Progress (ticked tasks, flashcards, best scores) is saved in the browser's `localStorage`, so it stays on the device and browser you use. Audio uses the device's built-in Korean text-to-speech voice.
